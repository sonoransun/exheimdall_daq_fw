HeIMDALL DAQ Firmware - bring-up instructions
=============================================

The step-by-step build notes that used to live in this file described the
Kerberos-era toolchain (rtl-sdr-kerberos driver, Python 3.8 from source) and
are long obsolete. This file is kept only so old references resolve.

Current instructions:

  * Quick start + build (Makefile ENGINE/BUILD/MARCH variables, copy-in
    dependencies, install.sh):        ../README.md
  * Automated installer:              ../util/install.sh
  * Reproducible CI-equivalent build: ../ci/build.sh generic|kfr|asan
  * Testing:                          ./unit_test.sh --ci   (hardware-free)
                                      sudo ./unit_test.sh --sudo  (pipeline)
  * In-depth documentation:           ../Documentation/
  * Contributor guide:                ../CONTRIBUTING.md

Note: the RTL-SDR driver must be the krakenrf fork
(https://github.com/krakenrf/librtlsdr) - the stock distro librtlsdr and the
old rtlsdrblog/rtl-sdr-kerberos repository referenced here previously do not
provide the required API.
